# 本地模型下载指南（Qwen2.5-3B-Instruct）

> 适用：后端 B | 模型路径：`models/Qwen2.5-3B-Instruct/`（已在 `.gitignore` 中，勿提交 Git）

## 下载什么

| 项目 | 值 |
|------|-----|
| 模型 | **Qwen2.5-3B-Instruct** |
| 用途 | 多 Agent 决策分析（生成文字） |
| 大小 | 约 6GB |
| 是否需要训练 | **否**，下载预训练权重即可 |

---

## 第 0 步：确认环境

```bash
python3 -c "import torch; print('cuda:', torch.cuda.is_available())"
```

必须输出 `cuda: True`（否则先修复 PyTorch cu124，见团队文档）。

安装依赖：

```bash
pip install transformers accelerate sentencepiece huggingface_hub \
  -i https://mirrors.aliyun.com/pypi/simple/ --trusted-host mirrors.aliyun.com
```

---

## 第 1 步：创建目录

```bash
mkdir -p /ai/data/lyr/muti-agent/models
```

Windows 示例：

```powershell
mkdir D:\muti-agent\models
```

---

## 第 2 步：下载模型（三选一）

### 方式 A：Hugging Face 镜像（推荐，Linux 服务器）

```bash
export HF_ENDPOINT=https://hf-mirror.com

# 新版 CLI（不要用已废弃的 huggingface-cli）
hf download Qwen/Qwen2.5-3B-Instruct \
  --local-dir /ai/data/lyr/muti-agent/models/Qwen2.5-3B-Instruct
```

### 方式 B：Python 脚本（网络不稳定时可重跑，支持断点）

在 `backend/scripts/` 下执行：

```bash
cd /ai/data/lyr/muti-agent/backend
python scripts/download_model.py
```

### 方式 C：ModelScope（国内）

```bash
pip install modelscope
python -c "
from modelscope import snapshot_download
snapshot_download(
    'qwen/Qwen2.5-3B-Instruct',
    local_dir='/ai/data/lyr/muti-agent/models/Qwen2.5-3B-Instruct'
)
"
```

### 方式 D：本机浏览器 + 网盘（服务器网络差时）

1. 打开 https://hf-mirror.com/Qwen/Qwen2.5-3B-Instruct/tree/main  
2. 下载全部文件到 `models/Qwen2.5-3B-Instruct/`  
3. 或上传百度网盘，在服务器解压到同路径  
4. 在 zip 中放 `大文件网盘链接.txt` 供老师下载（课程要求）

## 第 3 步：检查文件是否完整

目录中至少应包含：

```
models/Qwen2.5-3B-Instruct/
├── config.json
├── tokenizer.json
├── tokenizer_config.json
├── model.safetensors   （或 model-00001-of-00002.safetensors 等分片）
└── ...
```

```bash
ls -lh /ai/data/lyr/muti-agent/models/Qwen2.5-3B-Instruct/
du -sh /ai/data/lyr/muti-agent/models/Qwen2.5-3B-Instruct/
```

体积约 **5~7GB**。若只有几 MB，说明未下完。

---

## 第 4 步：运行测试

```bash
cd /ai/data/lyr/muti-agent/backend
python scripts/test_local_llm.py
```

成功：打印 `cuda available: True` 和一段**中文回复**，最后一行 `✅ 本地模型测试通过`。

---

## 第 5 步：写入配置（下一步接业务代码时用）

复制 `os.env.example` 为 `os.env`，增加：

```env
LLM_BACKEND=local
LOCAL_MODEL_PATH=/ai/data/lyr/muti-agent/models/Qwen2.5-3B-Instruct
LOCAL_MAX_NEW_TOKENS=2048
LOCAL_TEMPERATURE=0.7
```

---

## 常见问题

| 问题 | 处理 |
|------|------|
| `huggingface-cli` 不可用 | 改用 `hf download` |
| SSL / EOF 错误 | 换 ModelScope、换网络、或本机下载后 scp 到服务器 |
| OOM | 关闭占用 GPU 的其他进程；或先用 1.5B |
| 生成乱码/英文 | 确认用的是 **Instruct** 版，不是 Base |
